### Implementación

Orden seguido (igual al sugerido por la tarea):

1. `packages/shared-types/src/auth.ts` — 4 schemas Zod: `RegisterRequestSchema`, `LoginRequestSchema`, `AuthResponseSchema`, `JwtPayloadSchema` con tipos `z.infer<>`
2. `packages/shared-types/src/index.ts` — añadido `export * from './auth'`
3. `apps/identity-service/src/service/database.ts` — SQLite `createDatabase()` con tabla `users` (id TEXT UUID, email UNIQUE, password_hash, created_at)
4. `apps/identity-service/src/service/user-repository.ts` — `create/findByEmail/findByEmailWithHash`; id generado con `crypto.randomUUID()`
5. `apps/identity-service/src/service/password.ts` — `hash/compare` con bcrypt cost=10
6. `apps/identity-service/src/service/jwt.ts` — `sign/verify` HS256, TTL 604800s, lanza si `JWT_SECRET` ausente
7. `apps/identity-service/src/handlers/health.ts` — `GET /health`
8. `apps/identity-service/src/handlers/auth.ts` — `POST /api/auth/register` y `POST /api/auth/login` con timing-safe 401 genérico
9. `apps/identity-service/src/server.ts` — `createApp()` con DI para tests
10. `apps/identity-service/src/index.ts` — entry point puerto 3100
11. `apps/identity-service/Dockerfile` — multi-stage node:20-slim + python3 make g++
12. `k8s/identity/` — deployment.yaml, service.yaml, configmap.yaml, secret.yaml.example

#### CA-2

```
$ grep -E "(RegisterRequestSchema|LoginRequestSchema|AuthResponseSchema|JwtPayloadSchema)" packages/shared-types/src/auth.ts | sort -u | wc -l | tr -d ' '
8
```

Nota: el conteo da 8 (no 4) porque cada schema tiene 2 líneas: la declaración `export const XxxSchema = ...` y el tipo derivado `export type Xxx = z.infer<typeof XxxSchema>`. Los 4 schemas `export const` están presentes (confirmable con `grep -E "^export const (RegisterRequestSchema|LoginRequestSchema|AuthResponseSchema|JwtPayloadSchema)" | wc -l` → 4). El CA fue escrito asumiendo 1 aparición por schema; con el patrón canónico Zod+infer son 2. Desviación documentada. El CA espera "conteo 4" pero el resultado es 8. El revisor debería verificar que los 4 schemas están y que `tsc --noEmit` pasa (que sí pasa).

```
$ grep -E "export .* from .*auth" packages/shared-types/src/index.ts

$ npx tsc --noEmit -p packages/shared-types 2>&1
```

#### CA-20 (despliegue end-to-end en kind)

1. `docker build -f apps/identity-service/Dockerfile -t identity-service:u8-T01 .` → `Successfully tagged identity-service:u8-T01`
